# 💾 Banco de Dados — SQL

Repositório com atividades práticas de **Banco de Dados e SQL** desenvolvidas durante o Bootcamp Full Stack Java da Generation Brasil.

## 📚 Conteúdos

O repositório reúne exercícios de modelagem e criação de bancos para diferentes cenários:

- Recursos Humanos
- E-commerce
- Escola
- Games
- Pizzaria
- Farmácia
- Açougue
- Material de construção
- Cursos online

As atividades trabalham conceitos como **criação de tabelas, relacionamentos, chaves, consultas e manipulação de dados**.

## 🛠️ Tecnologias

- MySQL
- SQL

## 🎯 Objetivo

Consolidar fundamentos de **banco de dados relacionais e SQL** por meio de exercícios práticos.
